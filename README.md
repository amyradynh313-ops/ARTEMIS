# آرتمیس (Artemis) — راهنمای دیپلوی روی Render

این پروژه یه اپ Node.js + Express هست که هم صفحه اصلی (`public/index.html`) و هم
یه پنل مدیریت ساده (`public/admin.html`) رو سرو می‌کنه، و سهمیه روزانه +
اشتراک کاربرا رو روی خود سرور (نه توی مرورگر کاربر) نگه می‌داره.

## ساختار پروژه
```
artemis-server/
  server.js          سرور Express + همه API ها
  package.json
  data/db.json        دیتابیس ساده (فایل JSON)
  public/index.html   صفحه اصلی اپ
  public/admin.html   پنل ساخت کد اشتراک
```

## قدم ۱: آپلود روی گیت‌هاب
1. یه ریپازیتوری جدید توی گیت‌هاب بساز (مثلاً `artemis-app`).
2. همه‌ی فایل‌های این پوشه رو (به جز `node_modules` اگه ساخته شده) آپلود کن.
   می‌تونی از سایت گیت‌هاب دکمه "Add file → Upload files" رو بزنی، نیازی به خط فرمان نیست.

## قدم ۲: ساخت سرویس روی Render
1. وارد [render.com](https://render.com) شو و با گیت‌هاب لاگین کن.
2. New → Web Service رو بزن و ریپازیتوری‌ای که ساختی رو انتخاب کن.
3. تنظیمات:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** Free کافیه برای شروع
4. توی بخش **Environment Variables** این متغیرها رو اضافه کن:
   - Key: `ADMIN_PASSWORD` — Value: یه رمز قوی و دلخواه برای پنل مدیریت
   - Key: `ANTHROPIC_API_KEY` — Value: کلید API چت (از console.anthropic.com)
   - Key: `HF_API_KEY` — Value: کلید API هاگینگ‌فیس (از hf.co/settings/tokens) — برای ساخت واقعی عکس
5. دکمه Create Web Service رو بزن. بعد از چند دقیقه، یه آدرس مثل
   `https://artemis-app.onrender.com` بهت میده.

## قدم ۳: استفاده
- **صفحه اصلی کاربرا:** `https://آدرس-رندر-تو/`
- **پنل مدیریت (ساخت کد اشتراک):** `https://آدرس-رندر-تو/admin.html`
  رمزی که توی `ADMIN_PASSWORD` گذاشتی رو اونجا وارد کن، پلن (۱ ماهه یا ۳ ماهه)
  رو انتخاب کن و دکمه "ساخت کد جدید" رو بزن. کد ساخته‌شده رو برای کاربری
  که توی تلگرام (`@Amir56743`) بهت پول داده، ارسال کن. کاربر اون کد رو توی
  صفحه اشتراک برنامه وارد می‌کنه و اشتراکش فعال میشه.

## نکته‌ی مهم درباره‌ی ذخیره‌سازی داده‌ها ⚠️
دیتابیس این پروژه یه فایل ساده‌ی JSON (`data/db.json`) روی خود سرور هست، نه
یه دیتابیس واقعی. این برای شروع کار و تعداد کاربر کم کاملاً کافیه، اما:
- روی پلن **رایگان** Render، اگه سرویس مدتی بیکار بمونه خاموش میشه و فایل
  دیتا معمولاً حفظ میشه، ولی بعضی وقت‌ها با هر **دیپلوی جدید** (وقتی کد رو
  آپدیت می‌کنی) این فایل ریست میشه و اطلاعات کاربرا (سهمیه و اشتراک) از بین میره.
- وقتی تعداد کاربرا بیشتر شد یا خواستی مطمئن باشی داده‌ها هیچ‌وقت پاک نشن،
  بهتره یه دیتابیس واقعی (مثلاً PostgreSQL که خود Render هم به‌صورت رایگان
  ارائه میده) جایگزین این فایل JSON بشه. اگه خواستی، می‌تونم اون بخش رو هم
  برات آماده کنم.

## بخش چت با هوش مصنوعی 💬 (این یکی واقعیه، نه شبیه‌سازی)
برخلاف بخش ساخت عکس، بخش چت واقعاً به هوش مصنوعی (مدل Claude از Anthropic) وصله.
1. برو به **console.anthropic.com** و یه حساب بساز
2. یه API Key بساز (بخش API Keys)
3. همون کلید رو توی Render، Environment Variables، با نام `ANTHROPIC_API_KEY` ست کن
4. سرویس رو دوباره Deploy کن (یا Render خودش با تغییر env var ری‌استارت می‌کنه)

هر کاربر رایگان روزی ۱۰ پیام چت داره؛ کاربرای مشترک نامحدودن. این عدد رو
می‌تونی توی `server.js` با تغییر `CHAT_DAILY_LIMIT` عوض کنی. **توجه:** هر
پیام چت هزینه‌ی کمی از حساب Anthropic تو کم می‌کنه، پس این محدودیت روزانه
برای جلوگیری از هزینه‌ی زیاد گذاشته شده.

## بخش ساخت عکس 🖼️ (این هم واقعیه، وصل به Hugging Face)
1. برو به **huggingface.co** و ثبت‌نام کن
2. برو به **hf.co/settings/tokens** و یه توکن جدید بساز (نوع Read کافیه)
3. توکن رو توی Render، Environment Variables، با نام `HF_API_KEY` ست کن
4. سرویس رو Redeploy کن

مدل پیش‌فرض `black-forest-labs/FLUX.1-schnell` هست (سریع و رایگان روی Hugging
Face). چون ۴ تا "مدل" توی اپ برای انتخاب گذاشتیم ولی فقط یه مدل واقعی وصل
کردیم، هرکدوم از این گزینه‌ها یه سبک متفاوت (جزئیات بالا، رنگی و هنری،
رئالیستی و سینمایی) رو به پرامپت کاربر اضافه می‌کنن — نتیجه واقعاً فرق می‌کنه
ولی همه از یه مدل عبور می‌کنن. اگه بعداً خواستی هرکدوم واقعاً یه مدل جدا
باشه، توی `server.js` بخش `MODEL_STYLE_SUFFIX` رو می‌تونیم به چند مدل واقعی
مختلف (هرکدوم `HF_IMAGE_MODEL_nova`, `HF_IMAGE_MODEL_pulsar` و...) تبدیل کنیم.

**نکته:** مدل‌های هاگینگ‌فیس گاهی وقتی مدتی استفاده نشدن "خواب" میرن و اولین
درخواست باهاشون خطای «در حال بارگذاری» میده — برنامه این خطا رو به کاربر
نشون میده و میگه چند ثانیه صبر کنه و دوباره امتحان کنه.

## بخش ویدیو 🎬
ساخت ویدیوی واقعی با هوش مصنوعی هنوز وصل نشده. دلیلش اینه که اکثر مدل‌های
ویدیو روی هاگینگ‌فیس یا خیلی کندن (چند دقیقه طول می‌کشه، و سرور رایگان
Render معمولاً درخواست‌های طولانی رو قطع می‌کنه)، یا نیاز به حساب Pro /
Dedicated Endpoint دارن که هزینه‌ی جداگونه داره. فعلاً این بخش "به‌زودی"ه؛
اگه خواستی، می‌تونیم بعداً با یه سرویس مخصوص ویدیو (مثل fal.ai که سریع‌تره)
اضافه‌ش کنیم.
